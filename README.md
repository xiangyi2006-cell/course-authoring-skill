# Course Authoring Skill 技术课程撰写技能

> 一个可复用的课程撰写方法论与工具集，沉淀自一次完整的课程开发实践。
> 适用于 Claude Code / Cursor 等 AI 编程助手，也可作为人类课程作者的独立参考。

## 解决什么问题

技术课程写作中最常见的失败模式：

| 失败 | 后果 | 本技能的对策 |
|---|---|---|
| 开头甩概念，读者不知道为什么要在意 | 前三节流失率最高 | 每讲从场景/痛点切入 |
| 讲义之间没有衔接，知识散落 | 读者学到工具篇就懵了 | 承接链设计 + 系列级路线图 |
| 概念引用无出处，翻译走样 | 课程可信度崩塌 | A~D 来源分级 + 溯源台账 |
| 图是网图没有版权和解释 | 图文两张皮 | matplotlib 自绘 + 图注标注概念出处 |
| 代码跑不通或不知道成功长什么样 | 实战课变玄学课 | 完整可运行 + 每步标注预期输出 |
| 加粗在部分渲染器显示为星号 | 中文标点紧贴 `**` 的 CommonMark 陷阱 | 自动扫描修复 |
| 章节之间详略悬殊 | 读者体感不一致 | 统一拆解深度标准 |

## 快速开始

### 在 Claude Code / ZCode 中使用

1. 将 `SKILL.md` 复制到你的项目的 `.claude/skills/` 目录
2. 对 AI 说："帮我设计一门 XX 课程" 或 "写第 N 讲"
3. AI 将按照 SKILL.md 中的方法论执行

### 作为独立参考

直接阅读 `SKILL.md`——它本身就是一份完整的课程写作方法论，包含：

- 定位公式与路线图设计
- 来源分级与溯源台账
- 逐讲结构与语言规范
- 配图规范与脚本
- 终审检查清单
- 反模式速查表

## 核心原则速览

1. **衔接是生命线**：每讲开头回答"上一篇到哪了 → 为什么需要这个"
2. **类比先行，公式退后**：先直觉后精确，但精确不能省
3. **溯源是底线**：二手翻译只当线索，引用必须回溯到原始出处
4. **拆解式讲解**：一次只推进一小步，每个机制配走查
5. **实战可运行**：代码完整可抄，每步标注成功长什么样
6. **诚实局限**：每个方案讲完给"什么时候不该用"
